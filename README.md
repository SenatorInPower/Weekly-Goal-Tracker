# Weekly Goal Tracker

PWA-приложение для ежедневного трекинга задач и привычек с фокусом на недельный прогресс.

## Возможности

- **Управление задачами** — создание, редактирование, удаление, drag & drop сортировка
- **Категории** — Work, Health, Study, Personal, Other (цветовая маркировка)
- **Недельная таблица** — визуальная сетка выполнения задач по дням
- **Статистика** — donut-чарт прогресса, стрики, категорийная статистика
- **Достижения** — 15 разблокируемых ачивок (Perfect Day/Week, Streak milestones, Early Bird и др.)
- **Челленджи** — "Good Girl"/"Good Boy" + кастомные с визуальной сеткой дней
- **Шаблоны задач** — No alcohol, Exercise, Meditation, Reading, Water intake и др.
- **11 языков** — RU, EN, TH, ES, DE, FR, ZH, JA, UK, PT, KO
- **Тёмная/светлая тема**
- **Звуковая обратная связь** и браузерные уведомления
- **Экспорт/Импорт** — JSON backup и восстановление
- **PWA** — оффлайн поддержка, установка на домашний экран

## Технологии

| Технология | Детали |
|-----------|--------|
| Frontend | Vanilla HTML5, CSS3, JavaScript (без фреймворков) |
| Хранилище | localStorage |
| PWA | Service Worker, manifest.json |
| Аудио | Web Audio API |
| Уведомления | Notifications API |

## Структура

```
Tracker/
├── index.html         # Основное приложение (всё в одном файле)
├── manifest.json      # PWA-конфигурация
├── sw.js              # Service Worker
├── icon-192.png       # Иконка приложения
└── icon-512.png       # Иконка (большая)
```

## Использование

Откройте `index.html` в браузере или разверните на любом веб-сервере. Приложение полностью клиентское, данные хранятся в localStorage.
